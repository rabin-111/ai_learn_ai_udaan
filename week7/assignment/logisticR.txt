how can logistic regression be implemented in dp lms? 

logistic regression is different from normal linear regression as linear regression predicts the value in numerical form but logistic is for binary classification problem .
it is a supervised machine learning
it predicts the probability that an input belongs to a specified class.
it uses sigmoid function ie s curve which have 1/(1+e^-z) such that it intercepts y axis at 0.5.
it converts the raw output of linear regression into a probability between 0 and 1
if ouput >= 0.5 it is considered as 1 and if <0.5 then output considered as 0.

it can be directly implemented from sklearn
model =LogisticRegression()
model.fit(X,y)
prediction=model.predict([[4.5]])
prediction[1] --> gives predicted class
prediction[0][0] --> gives probability of failing
prediction[0][1] --> gives probability of passing.
