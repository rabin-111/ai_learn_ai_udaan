## 📂 What You'll Find Here

### 🐍 1. Python Fundamentals

Building the programming foundation required for data science and machine learning.

- Variables, data types, operators, and input/output
- Conditional statements and loops
- Lists, tuples, sets, and dictionaries
- Functions, parameters, arguments, and return values
- Built-in functions and useful Python methods
- Iteration, `map()`, `filter()`, and sorting
- Object-oriented programming
- Generators, decorators, and other useful concepts

### 🔢 2. NumPy — Numerical Computing

Learning to work efficiently with numerical data and arrays.

- Creating and manipulating arrays
- Array indexing and slicing
- Array shapes, dimensions, and reshaping
- Sorting and searching arrays
- Statistical and mathematical operations
- Boolean indexing and filtering
- Working with multidimensional arrays

### 🐼 3. Pandas — Data Analysis

Learning how to explore, clean, transform, and analyze datasets.

- Series and DataFrames
- Reading CSV files and inspecting datasets
- Selecting rows and columns
- Filtering data using conditions
- Handling missing values
- Data cleaning and type conversion
- Detecting duplicates and potential outliers
- Working with categorical and list-valued data
- Exploring datasets to identify useful patterns

### 📊 4. Matplotlib — Data Visualization

Learning to communicate information through visual representations.

- Line plots and bar charts
- Histograms and scatter plots
- Figure and axis customization
- Titles, labels, legends, and grids
- Visualizing distributions and relationships in datasets

### 🤖 5. Scikit-learn — Machine Learning

Developing an understanding of the workflow used to train and evaluate machine learning models.

- Preparing features and target variables
- Training and testing datasets
- The `fit()` and `predict()` workflow
- Classification fundamentals
- Decision trees and other introductory algorithms
- Model evaluation and cross-validation
- Understanding overfitting and generalization

## ✍️ Handwritten Notes & Study Materials

Alongside the code, I share handwritten notes prepared by me during my learning process.

These notes focus on useful concepts, commonly used methods, syntax, and explanations that can be revisited quickly during revision.

**My recommendation:** Use the handwritten notes as a reference, not as a substitute for coding practice.

Reading a method and understanding its definition does not automatically mean you can apply it. Open your computer, write the code, experiment with it, and practice using different examples.

The combination of **notes + coding + experimentation** is what makes the concepts stick.
